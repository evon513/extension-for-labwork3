## Плагин insertCodeCommand
- Плагин заменяет короткую запись for(name, start, end, step) на вставку преобразованную к виду c++.
- также он игнорирует количество пробелов, поставленных между аргументами, важен лишь их порядок. 
- он учитывает и обратный порядок, когда start > end.
- имеет горячие клавиши CTRL+ALT+F

## ТЗ
 Написать дополнение, которое заменяет короткую запись цикла формата:

```c++
for(i,2,10)
//или же 
for(name, start, end, step)
```
- на приемлимый вид:
``` c++
for (int i=start; i < end; i+=step){
    ...
}
```

## Описание функций
* Options

Интерфейс, который хранит в себе параметры name, start, end, step
* Parsing(txt) -> Options

Разбивает строку на аргументы name, start, end, step

* BuildFor(Options) -> string

Собирает правильный цикл for с помощью заранее распаршенных аргументов

## Примеры вызова функций
txt = for(i, 9, 3, 2)

- Parsing(txt) -> {name=i, start=9, end=3, step=2}

Options = {name=i, start=9, end=3, step=2}

- BuildFor(Options) -> for (int i=9; i>3; i-=2){ 

}
